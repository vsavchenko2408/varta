## Varta 0.4.0 — перший реліз

Перша опублікована версія інтерактивного файрвола для Windows (і Linux зі збірки з коду).

**Встановлення на Windows:** завантажте `Varta-0.4.0-windows-x64.zip`, розпакуйте й двічі клацніть
`install.cmd`. Якщо Varta вже стоїть — просто запустіть його так само: правила й налаштування збережуться.

### Нове
- **Перевірка оновлень.** Раз на день (можна вимкнути в «Налаштування → Оновлення») Varta
  перевіряє, чи вийшла нова версія, і пропонує встановити її в один клік. Завантажений файл
  звіряється з контрольною сумою SHA-256, яку публікує GitHub.
- Один номер версії для всієї програми (інтерфейс, служба й утиліта показують однаковий).
- Повторне встановлення не завантажує базу IP заново (оновити вручну: `vartad --update-db`).

### Виправлено раніше (входить у цей реліз)
- Інтерфейс більше не відкриває вікно терміналу.
- `install.cmd` — встановлення подвійним клацанням.
- Зворотний DNS у вікні запиту більше не відправляє NetBIOS-запитів на чужі адреси.
