## Varta 0.5.0 — macOS

### Нове
- **Інтерактивний файрвол для macOS** (Mac з Intel, macOS 12+). Показує кожне нове з'єднання:
  програму, хост, власника IP і країну, питає вас і блокує заборонене через pf.
  Встановлення: розпакуйте `Varta-0.5.0-macos-x64.zip` і виконайте `sudo sh install.sh`.
  Режим «побачити й заблокувати»: перші пакети встигають вийти, а заборона діє на адресу для
  всіх програм (подробиці — у README).
- На Windows і macOS ця версія приходить через вбудоване автооновлення.

### Інше
- Однакові пакети для всіх платформ збираються й тестуються на GitHub, на macOS — разом із
  запуском служби, блокуванням через pf та інсталятором.
