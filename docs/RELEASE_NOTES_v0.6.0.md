## Varta 0.6.0 — непрохані вхідні пакети

### Нове
- **Блокування непроханих вхідних пакетів з інтернету** (Налаштування, типово ввімкнено).
  Відповіді на ваші з'єднання й локальна мережа проходять.
  - **Windows:** Varta вмикає вбудований брандмауер Windows лише для вхідного трафіку й **без його
    спливних вікон**. Програми, яким ви дозволили вхідні з'єднання у Varta, автоматично
    отримують правило там. Попередні налаштування брандмауера повертаються, якщо вимкнути опцію
    або видалити Varta.
  - **macOS:** UDP з інтернету, що не є відповіддю, відкидається через pf.
  - **Linux:** як і раніше — нові вхідні з'єднання (TCP і UDP) Varta показує й питає.
- `varta apply` на Windows попереджає й питає, перш ніж увімкнути брандмауер Windows.
